# apps

Прикладные приложения платформы. Каждое приложение - **тонкая** оболочка: маршруты, конфигурация сборки, подключение доменов и модально-специфичного модуля визуализации.

| Каталог | npm name | Порт dev | Контур |
|---------|----------|----------|--------|
| `ultrasound/` | `ultrasound-app` | 3002 | 2D (УЗИ) |
| `cytology/` | `cytology-app` | 3001 | 2D (цитология) |
| `ct/` | `ct-app` | 3004 | DICOM (КТ) |
| `mri/` | `mri-app` | 3005 | DICOM (МРТ) |

Запуск: `npm run dev:<модальность>` из корня репозитория.

Модально-специфичный код размещается в `src/features/` приложения (`features/uzi-view`, `features/cytology-view`) и не импортируется другими apps. В `src/pages/` лежат только тонкие обёртки маршрутов (`*Route.tsx`), подключённые в `routes.tsx`.

Внутри модально-специфичного модуля код группируется по назначению, а не сваливается плоским списком — например, `features/uzi-view`:

```text
uzi-view/
├── UziViewPage.tsx   # композиция страницы
├── viewer/           # аннотирование поверх @medml/viewers (Annotorious)
├── gallery/          # подготовка кадров снимка и тулбар редактирования
├── sidebar/          # блоки правой панели
├── structures/       # структуры ЩЖ: типы, загрузка JSON, хранение, превью
└── model/            # DTO бэкенда и хуки бизнес-логики
```

Пропсы компонентов объявляются рядом с компонентами; в `model/types.ts` живут только DTO бэкенда.

# Обзор архитектуры

Клиентская платформа **medml-front** - монорепозиторий семейства диагностических приложений (УЗИ, цитология, КТ, МРТ).

## Уровни

```
apps/      → прикладные приложения (маршруты, композиция)
domains/   → общие предметные контексты (пациенты, auth, layout)
lib/       → инфраструктура и модули визуализации
configs/   → общие пресеты TS / Vite / ESLint
tools/     → скрипты проверки границ и обслуживания workspaces
build/     → Docker, Nginx, поставка статики
```

## Контуры визуализации

- **2D** (`@medml/viewers`, Annotorious) - УЗИ, цитология
- **DICOM** (`@medml/ct-mri-viewer`, Cornerstone) - КТ, МРТ

Общий каркас (авторизация, списки, UI) переиспользуется; модально-специфичный код изолирован в приложениях или пакетах `lib`.

## Рабочее место врача над снимком

Просмотр 2D-снимка разложен на три уровня - так УЗИ и цитология получают
одинаковый набор возможностей из одного кода:

| Уровень | Пакет | Что содержит |
|---------|-------|--------------|
| Страница | `@medml/study_view` (domain) | Режим фокуса, раскладка "сводка / снимок / панель" |
| Рабочее место | `@medml/viewers` → `AnnotatedStudyViewer` | Инструменты, линейка с калибровкой, кисть, легенда, состояния |
| Движок | `@medml/viewers` → `UziViewer` | OpenSeadragon: zoom/pan/rotate, кадры, слоты расширения |

Инструменты разделены по режимам: навигация, линейка и задание масштаба
доступны и при просмотре (они ничего не меняют), рисование и кисть - только
в режиме редактирования.

Библиотека разметки в общий вьюер не попадает: приложение отдаёт слой через
контракт `ViewerAnnotationLayer` (`attach` / `detach` / `setTool` / `addPolygon`).
Поэтому УЗИ работает на Annotorious 2, цитология - на Annotorious 3, а
вьюер у них один и тот же.

# Дизайн-система и вёрстка блоков

Источник: Figma «Второе мнение — Redesign Mockups» → страница `01 — Design System`.
Код: [`lib/ui/src/theme/tokens.ts`](../../lib/ui/src/theme/tokens.ts) (TS) и
[`lib/ui/src/styles/tokens.scss`](../../lib/ui/src/styles/tokens.scss) (SCSS).

## 1. Где что лежит

| Слой | Файл | Назначение |
|---|---|---|
| Примитивы | `lib/ui/src/theme/tokens.ts` | Единственный источник правды: цвет, шрифты, радиусы, тени, сетка |
| Тема antd | `lib/ui/src/theme/config.ts` | `ThemeConfig` — собирается из токенов, ни одного «сырого» hex |
| SCSS | `lib/ui/src/styles/tokens.scss` | Зеркало токенов для стилей вне antd |
| Провайдер | `lib/ui/src/providers/AntDesignProviderSpa` | Единственное место, где тема подключается |

Приложения **не** заводят собственные `tokens.scss`: `apps/ultrasound/src/styles/tokens.scss` —
это `@forward '@medml/ui/styles/tokens'`. Раньше здесь была копия, и копии разошлись.

### Легаси-переменные

В конце `tokens.scss` есть блок `LEGACY-совместимость` — старые имена
(`$line-height-base`, `$font-size-base`, `$color-background-body`,
`$font-family-secondary` и др.) с исходными значениями. Их используют
`reset.scss`, `mixins.scss`, `Header.scss`.

**Не удаляйте их, не проверив потребителей** — sass падает на этапе сборки
(`Undefined variable`), а не при typecheck. Проверка:

```bash
grep -rn '\$имя-переменной' --include="*.scss" apps domains lib
```

Новые экраны легаси-имена не используют: для них есть семантические токены выше.

> Учтите: `$spacing-*` в дизайн-системе перешли на шкалу 4px (`sm` = 8px),
> тогда как в старом наборе были 10/20/30/100px. `Header.scss` и `auth.scss`
> определяют свои `$spacing-*` локально, поэтому их это не задело, — но при
> переводе этих файлов на общие токены отступы поедут, и это ожидаемо.

## 2. Токены

### Цвет — правило 60 / 30 / 10

Нейтральные Slate доминируют, navy задаёт структуру, **cyan применяется точечно**.
Если бирюзовый занимает больше ~10% экрана — это ошибка, а не «ярче и заметнее».

| Роль | Значение | Где |
|---|---|---|
| Brand Navy | `#0F172A` | Основной текст, сплошные кнопки, шапки |
| Teal-Cyan | `#06B6D4` | AI-акцент, фокус, ссылки, активные состояния |
| Bright Blue | `#3B82F6` | Вторичный акцент, hover, начало AI-градиента |
| Slate 50 | `#F8FAFC` | Фон страницы |
| Slate 200 | `#E2E8F0` | Границы |
| Slate 500/600 | `#64748B` / `#475569` | Вторичный текст, иконки |

Статусы завязаны на TI-RADS — для этого есть `tiradsTone` в `theme/config.ts`:

| Статус | Текст | Фон | TI-RADS |
|---|---|---|---|
| Норма | `#10B981` | `#ECFDF5` | 1–2 |
| Наблюдение | `#F59E0B` | `#FFFBEB` | 3–4 |
| Высокий риск | `#E11D48` | `#FFF1F2` | 5 |
| AI / инфо | `#06B6D4` | `#ECFEFF` | — |

Градиент `#3B82F6 → #06B6D4` — **только** логотип и AI-акценты. Не использовать как фон кнопок и карточек.

### Типографика

Два шрифта с разными задачами:

- **Onest** — заголовки и весь UI.
- **Inter** — числа: измерения, проценты, значения в таблицах и плитках метрик. У Inter табулярные цифры, поэтому колонки чисел не «пляшут».

| Роль | Размер / вес | Трекинг |
|---|---|---|
| Display | 60 Bold | −1.2 |
| H1 | 48 Bold | −0.96 |
| H2 | 36 Bold | −0.72 |
| H3 | 30 SemiBold | 0 |
| H4 | 24 SemiBold | 0 |
| Body | 16 Regular | 0 |
| Body sm / Label | 14 Regular / 14 Medium | 0 |
| Caption | 12 Regular | 0 |
| Eyebrow (капс) | 12 SemiBold | +0.96 |
| Metric | Inter 40 Bold | 0 |

У крупных заголовков трекинг **отрицательный** — без него H1/H2 выглядят разреженными.

### Сетка, радиусы, тени

- Сетка **4px**: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 80. Другие значения отступов не использовать.
- Радиусы: `xs 6` · `sm 10` · **`md 14` (инпуты, алерты)** · `lg 18` · **`xl 24` (карточки)** · `2xl 32` · **`full` (кнопки, чипы, сегменты)**.
- Тени строятся на navy, а не на чёрном: `rgba(15,23,42,α)`. Чёрные тени на светлом фоне выглядят грязно.
  `xs` → `sm` → **`card` (дефолт карточек)** → `md` → `lg`.
- Фокус: кольцо `0 0 0 4px rgba(6,182,212,0.18)` + бордер cyan. Убирать `outline` без замены нельзя — это доступность.

## 3. Компоненты antd

Тема уже настроена, поэтому **штатные компоненты выглядят правильно без правок**. Не переопределяйте стили инлайном, если это уже покрыто темой.

| Макет | antd | Примечание |
|---|---|---|
| Pill-кнопка navy | `<Button type="primary">` | Радиус и цвет из темы |
| Pill-кнопка cyan (CTA) | `accentButtonTheme` + `<Button type="primary">` | Или `<Button color="cyan" variant="solid">` на antd ≥ 5.21 |
| Кнопка-контур | `<Button>` | Бордер slate-300 |
| Текстовая cyan | `<Button type="link">` | |
| Чип статуса | `<Tag>` | Цвета — через `tiradsTone` |
| Плашка | `<Alert showIcon={false}>` | Радиус 14, паддинг 18 |
| Переключатель | `<Segmented>` | Трек slate-100, активная опция белая |
| Плитка метрики | `<Card>` + `Inter 40 Bold` | Подпись — Eyebrow 11–12 капсом |

Цвет узлов на снимке (`NODE_COLORS`) — **не** часть этой палитры: там нужна максимальная различимость поверх серого УЗИ-изображения. Менять его надо отдельно и с оглядкой на дальтонизм.

## 4. Сетка и расположение блоков

Макет — колоночный поток с шагом 4px и внешним полем **80px** у секций верхнего уровня.

### Перенос в Layout / Row / Col

```tsx
<Layout>
  <Layout.Content>
    <WidthControl>            {/* max-width 1280 + боковые поля */}
      <Row gutter={[16, 16]}>  {/* gutter только из шкалы: 8/12/16/24 */}
        <Col xs={24} lg={16}>{/* основная область */}</Col>
        <Col xs={24} lg={8}>{/* правая панель */}</Col>
      </Row>
    </WidthControl>
  </Layout.Content>
</Layout>
```

Правила:

1. **Ширину держит `WidthControl`**, а не `maxWidth` на каждой странице. Значение — `$content-max-width` (1280).
2. **Между блоками — `Row gutter`**, а не `margin` у детей. Так отступы не схлопываются и остаются на шкале.
3. **Внутри карточки — `Space direction="vertical" size={16}`** или flex с `gap`, но опять же из шкалы.
4. **Брейкпойнты**: `xs` — одна колонка, `lg` — раскладка 16/8. Правая панель прячется первой, снимок отдаёт ширину последним.
5. **Не смешивайте `Row/Col` и flex на одном уровне** — выберите одно, иначе gutter'ы и gap складываются непредсказуемо.

### Отступы: что применять

| Ситуация | Значение |
|---|---|
| Между секциями страницы | 24 (`xl`) |
| Между карточками в ряду | 16 (`lg`) |
| Внутренний паддинг карточки | 24 (`xl`) |
| Между полем и подписью | 4–6 |
| Между элементами тулбара | 8 (`sm`) |

## 5. Правила стилей

- **Никаких hex в компонентах.** Только токены или тема antd.
- **Никаких `!important`.** Если стиль не применяется — это конфликт специфичности; решается темой antd или более точным селектором. В `apps/ultrasound` сейчас 0 `!important`, в `domains` (50), `apps/cytology` (43) и `lib` (12) — долг к вычистке.
- **Только `.scss`**, без `.css`-файлов и без `@import` внутри стилей: подключение — `@use`, шрифты — `<link>` в `index.html` (CSS-импорт блокирует рендер).
- Иконки — **Lucide**, обводка 1.5px, размеры 16/20/24, цвет наследуется через `currentColor`.
  Не использовать эмодзи, Unicode-символы и залитые иконки.
